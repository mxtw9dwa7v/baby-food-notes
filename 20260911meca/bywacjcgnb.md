# 5.12护士节| 落实责任、消除隐患、保证安全！护理部举办“护理安全百日”循环竞赛活动~

> 更新时间：2026-09-11 (UTC+8)

****
为进一步推动我院护理质量的持续改进，保障患者安全，提高医院管理水平，实现安全生产无事故，质量持续改进。护理部自2月份以来开展以“落实责任、消除隐患、保证安全”为主题的“护理安全百日”循环竞赛活动，全院共11个科室180余人参加了此次活动。
此次活动分为三大形式。本次活动分为学习培训、组织实施、总结评价三个阶段进行。

**（一）学习培训阶段**

首先，从二月份起，护理部开始组织全院护理人员在钉钉上学习高院长讲解的《患者安全目标的落实》视频，并制定实施方案，组织全员学习。

我院护理工作者认真听讲，积极学习，明确护理工作的重点、难点，不断强化护理安全意识，使得临床护理工作得到进一步规范。

**（二）组织实施阶段**

在完成学习培训后，各科室护士长积极组织科室护士按照活动内容查找护理风险点，制定隐患排查计划和相应对策，形成安全目标管理任务书，按照计划逐项落实，整改。

各科室护士结合自己的临床实际，查找安全隐患时间，防风险、保稳定，积极改善护理服务，提高护理质量，保障医疗安全。

**（三）总结评价阶段**

2021年五月份，正式进入总结评价阶段。分别从临床查验和现场汇报两个方面进行。
2021年5月6日-5月8日，护理部深入临床进行临床查检，对科室在临床实践中查检的项目和的实施对策进行评价打分。

经过查找问题、对策实施及科室现场互评，历时3个月的时间，医院护理安全意识得到进一步提升，护理安全得到进一步保障。为总结经验，5月11日，护理部举办“护理安全百日”循环活动总结汇报。各科室汇报人分别就查找出的安全隐患问题进行汇总，并对实施方案形成的效果进行总结评价，由护理部统一评价打分。

**竞赛结果出炉**

经过层层激烈的竞赛角逐和公正评审，最终竞赛结果新鲜出炉。

新生儿科夺得桂冠

妇科、产三科获得二等奖

手术室、产一科、产二科获得三等奖

比赛结束后，院长助理高荣花为此次活动作了点评。她表示：通过本次首阶段的百日安全循环活动，提高了护士长及全体人员对患者安全的重视程度，及思考架构。举全科之力解决了既往存在的顽疾及安全隐患，最主要是的改变了护理人员对安全问题的漠视和得过且过。希望大家继续努力学习，不断提高护理质量，始终把护理安全记在心中。

护理安全无小事，它需要我们持之以恒、谨小慎微的坚持；它需要我们不断改进、不断完善的努力，后续我们将进行第二阶段安全百日循环活动，将护理质量做到精益求精，为患者营造安全的诊疗环境，为工作人员打造顺畅、安全的工作氛围。“保障患者安全，有起点，没有终点”。护理安全，我们将一直在路上！
